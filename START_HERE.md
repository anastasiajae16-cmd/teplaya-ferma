# Тёплая ферма v0.8 — запуск и проверка

Этот архив содержит полный проект HTML5 без сборщика: код в `dist/`, картинки в `dist/assets/`, тесты в `tests/`, генератор архива для ВК в `scripts/`.

## Запуск игры локально

1. Распакуйте ZIP в отдельную папку, например `C:\Games\teplaya-ferma`.
2. Откройте PowerShell из этой папки.
3. Выполните `py -m http.server 8080 --bind 127.0.0.1 --directory dist`.
4. Перейдите в браузере на http://127.0.0.1:8080.

Если Python не установлен, откройте `dist/index.html` напрямую или используйте локальный сервер редактора.

## Что нового

- Разборка дерева, куста, забора, цветника, амбара, курятника, мастерской или стога сена через кнопку 🪓 справа.
- Прочность объектов и сохранение повреждений. Повторное нажатие по выбранному объекту наносит удар.
- Кнопка «Вернуть»: восстановление или ремонт за монеты; новые грядки мешают возвращению объекта на их место.
- Лёгкие анимации природы, урожая и животных с отключением в справке.
- Автоматическое сохранение прежнего прогресса при обновлении с v0.7.

## Проверка кода

При установленном Node.js: `node --test tests/*.test.cjs`. Релизный архив со строгой инициализацией ВК: `py scripts/package.py`.

Ссылка прежнего опубликованного варианта: https://teplaya-ferma.plainvenus1.chatgpt.site/
Новый ZIP сам по себе не обновляет эту ссылку. На другом адресе и устройстве свой прогресс браузера. Реальный клиент ВКонтакте и Android ещё требуют ручной проверки.
